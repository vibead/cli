- npm publishing is Trusted Publishing only (release.yml, OIDC with --provenance): never `npm login` or a publish token on the box. It needs npm 11.5.1 or newer and a public repo whose URL matches package.json `repository`. Moving a dist-tag through OIDC needs npm 11.21.0 or newer and **Allow npm dist-tag** ticked on the trusted-publisher entry (off by default); `release.yml` `mode: promote` does it, so never `npm login` to move a tag either. (cli#30, cli#58)
